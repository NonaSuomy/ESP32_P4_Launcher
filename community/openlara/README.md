# OpenLara

Native PAPP2 build of the OpenLara Tomb Raider 1 engine for ESP32-P4. The package contains the engine only; it does not include copyrighted game data.

Copy the `DATA` folder from a legally obtained Tomb Raider 1 PC installation to `/sd/roms/openlara/DATA/`. Level files such as `LEVEL1.PHD` and `TITLE.PHD` are required. Optional movies belong in `/sd/roms/openlara/FMV/`.

Source: [alexkid77/openlara_esp32p4](https://github.com/alexkid77/openlara_esp32p4) at `da3d43138f3a9eae6778c96adbdd7a6579e42979`; original engine by [XProger/OpenLara](https://github.com/XProger/OpenLara).

# Quake II

Native PAPP2 port of Quake II with the software renderer, gamepad and keyboard input, audio, and music support. It contains the engine only; no game data is included.

Place the shareware or retail `baseq2` directory under `/sd/roms/quake2/baseq2/`. Retail data is required for the full game. Start with the shareware data if available.

Source: [PAX Quake II port](https://github.com/NonaSuomy/RetroESP32-P4/tree/5c475e9df46c43463bd85c43f647d513d3b9bfa2/apps/quake2), based on [ESP32_QUAKE2](https://github.com/alexkid77/ESP32_QUAKE2) and id Software's GPL release. This build has not been tested on AIO hardware.

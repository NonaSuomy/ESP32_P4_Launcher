# Performous

Native PAPP2 rhythm and karaoke game for ESP32-P4. It provides a five-lane fretboard, gamepad and touch controls, threaded OGG backing audio, and timed UltraStar lyrics. Live vocal pitch scoring, desktop 3D rendering, and drum gameplay are not included.

Add songs under `/sd/roms/performous/<song-folder>/`. Each UltraStar chart should include its `.txt` file and the referenced audio file (usually OGG). No commercial songs are included.

Source: [PAX Performous port](https://github.com/NonaSuomy/RetroESP32-P4/tree/d0a449f9e2252881ab1ac297d05353f5bc58c046); based on [Performous](https://github.com/performous/performous) 1.3.1.
